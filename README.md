# Собери мишени — 9 блоков Kotlin

Все блоки 1–9 в одном приложении. Дополнительные задания отсутствуют.

## Самый надёжный способ запуска через стандартный шаблон Android Studio

1. Android Studio → New Project → **Empty Views Activity** (НЕ Empty Activity с Compose).
2. Название: `MagicBall`, package name: `com.example.magicball`, Language: **Kotlin**.
3. Открой `app/src/main/java/com/example/magicball/MainActivity.kt`.
4. **Полностью замени** его содержимое кодом из одноимённого файла в этом архиве.
5. Нажми Sync и Run. Остальные файлы стандартного шаблона не трогай.
6. Лучше запускать на настоящем телефоне, потому что для управления нужен акселерометр. На эмуляторе датчик можно имитировать в Extended Controls → Virtual Sensors.

Этот способ использует совместимые Gradle, JDK и SDK, которые Android Studio создаёт в новом проекте. Ни одна дополнительная библиотека не нужна.

## Запуск готовой папки как проекта

В архив также включены Gradle-конфигурация и AndroidManifest.xml. Для самостоятельного открытия готовой папки нужны установленный Android SDK 34, JDK 17 и Gradle 8.6. **Gradle Wrapper (gradlew, gradle-wrapper.jar) отсутствует**, поэтому предпочтителен способ с Empty Views Activity.

## Соответствие заданию

- Блок 1: цвета, размеры, количество мишеней и чувствительность.
- Блок 2: координаты, скорость, счёт и победа.
- Блок 3: Paint.
- Блок 4: акселерометр.
- Блок 5: Thread и isRunning.
- Блок 6: инициализация и создание мишеней.
- Блок 7: startGame и stopGame.
- Блок 8: игровой цикл, движение, отскоки, счёт, победа.
- Блок 9: наклон телефона.
